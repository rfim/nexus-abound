    The rule, as the pipeline runs it (src/nexus/silver.py)

    MERGE INTO lake.silver.<table> t USING silver_batch s ON t.<pk> = s.<pk>
  WHEN MATCHED AND s.change_seq > t.change_seq THEN UPDATE SET *     -- newest change_seq wins; a tombstone keeps its seq
  WHEN NOT MATCHED THEN INSERT *
  -- on a reload only:
  WHEN NOT MATCHED BY SOURCE AND NOT t.is_deleted THEN UPDATE SET t.is_deleted = true
